# PRODIGY_DS_02

# Titanic Survival Prediction and Data Analysis

## Project Overview

This project analyzes the famous Titanic dataset and explores the factors that influenced passenger survival during the Titanic disaster.

The project uses data analysis, visualization, and machine learning techniques to identify patterns and predict passenger survival based on demographic and travel-related information.


## Project Objectives

- Perform Exploratory Data Analysis (EDA)
- Identify factors affecting passenger survival
- Visualize survival trends
- Build a machine learning model to predict survival
- Evaluate model performance

- Pandas

- Matplotlib
- Seaborn
- Scikit-Learn
